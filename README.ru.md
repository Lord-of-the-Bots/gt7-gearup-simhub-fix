# GT7 / GearUP / SimHub — исправление маршрута телеметрии

[English](README.md)

PowerShell-скрипт для восстановления телеметрии Gran Turismo 7 в SimHub, когда ПК с Windows и GearUP используется как шлюз для PlayStation 5.

Игра может работать онлайн, но Windows отправляет запросы телеметрии через роутер вместо прямого обращения к приставке. Такое возможно, когда GearUP помещает PS5 в другую IP-подсеть. Скрипт добавляет постоянный прямой маршрут `/32` к приставке через выбранный сетевой адаптер ПК.

ПК и PS5 должны находиться в одной локальной сети на канальном уровне (Layer 2). Скрипт решает проблему маршрутизации, но не все возможные сбои GearUP и SimHub.

## Использование

Нужны Windows 11, Windows PowerShell 5.1 и права администратора. Дополнительные программы для скрипта не требуются.

1. [Скачайте ZIP](https://github.com/Lord-of-the-Bots/gt7-gearup-simhub-fix/archive/refs/heads/main.zip) и распакуйте его.
2. Включите GearUP. Посмотрите текущий IPv4-адрес PS5 в сетевых настройках приставки.
3. Запустите `Update-GT7-Route.cmd` и подтвердите запрос прав администратора.
4. Введите адрес PS5. Если появится выбор адаптера, укажите физический адаптер, подключающий ПК к локальной сети. Уже существующий маршрут к этому адресу можно передать под управление скрипта только после подтверждения.
5. В SimHub выберите Gran Turismo 7, укажите тот же адрес PS5 в **Console IP** и UDP-порт **33740**. Перезапустите SimHub и начните гонку.

Маршрут сохраняется после перезагрузки. Повторный запуск нужен при изменении адреса приставки или сетевого адаптера ПК.

## Удаление

Запустите `Remove-GT7-Route.cmd`. Он удаляет только маршруты, записанные как созданные скриптом или переданные под его управление. Состояние хранится в `C:\ProgramData\GT7-Telemetry-Route\state.json`; сохраните этот файл для обновления и удаления маршрутов.

## Если не работает

В скриптах, которые запрашивают пустое хранилище постоянных маршрутов с серверным фильтром IPv4, возможна ошибка:

```text
Не найдены объекты MSFT_NetRoute со свойством "AddressFamily", равным "IPv4"
```

Она не означает, что адрес PS5 не найден. Этот скрипт сначала получает содержимое хранилища маршрутов, затем фильтрует результат, поэтому пустое хранилище обрабатывается нормально.

Если телеметрии всё ещё нет, проверьте адрес приставки, выбранный локальный адаптер, правила брандмауэра Windows для SimHub и UDP **33739/33740**, а также другие приложения телеметрии, занимающие те же порты.
